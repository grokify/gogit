# gogit v0.13.1 Release Notes

**Release Date:** 2026-09-28

## Overview

A CI-only fix: v0.13.0's release build failed to attach prebuilt `gitscan`
binaries, and this ships those. No source code changes — the underlying Go
module was correct and usable at v0.13.0 either way (`go get`/`go install`
were never affected); only the optional binary distribution was broken.

## Fixed

### Release workflow's Go version no longer drifts from go.mod

`go.mod` requires Go >= 1.26 (raised by a Dependabot update to
`github.com/grokify/mogo`), but the release workflow still pinned Go 1.25
explicitly. GoReleaser's `before` hooks run with `GOTOOLCHAIN=local`, which
refuses to auto-fetch a newer toolchain, so the build failed before
producing any binaries. The workflow now reads its Go version from
`go.mod` (`go-version-file: go.mod`) instead of a hardcoded string, so this
can't silently drift out of sync again.

## Installation

```bash
go get github.com/grokify/gogit@v0.13.1
go install github.com/grokify/gogit/cmd/gitscan@v0.13.1
```
