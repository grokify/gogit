## [v0.10.0] - 2026-09-08

### Highlights

- Fleet-wide `gitscan pending`: sweep unpushed commits across many repositories at once by passing one or more paths (e.g. one per GitHub org you manage), reported per repo with a summary of how many repos were scanned and have work waiting
- New `gitscan pushed` subcommand and `Repo.PushedCommits` library API: the most recent commits already pushed on a branch — the counterpart to `pending` — so you can see recent activity on either side of what has reached the remote
- `gitscan pending` no longer errors on a branch with no upstream: a repo that was never pushed now reports every commit as pending, resolving the push baseline from the upstream or the matching remote-tracking branch (e.g. `origin/main`)
- Removed the `-d`/`--dir` flag: the scan directory is now a uniform optional positional argument across every subcommand, defaulting to the current directory

### Breaking

- The `-d`/`--dir` flag is removed from `gitscan` and `gitscan order`; pass the directory as a positional argument instead (e.g. `gitscan ~/go/src`, `gitscan order ~/go/src`) ([`542b9c6`](https://github.com/grokify/gogit/commit/542b9c6))
- `gitscan pending` and `gitscan pushed` JSON output changed from a single `{repo,mode,ref,count,commits}` object to an invariant `{"repos":[{…}],"summary":{…}}` envelope, so consumers never branch on the number of repositories reported ([`4cb1c1e`](https://github.com/grokify/gogit/commit/4cb1c1e))

### Added

- `gitscan pending [path...]`: accepts one or more repository or directory paths and reports every discovered repo (concurrently); repos with nothing pending are omitted from the table/markdown views and counted in the summary ([`4cb1c1e`](https://github.com/grokify/gogit/commit/4cb1c1e))
- `gitscan pending --depth`: how many directory levels below each path to search for repositories (default 1) ([`4cb1c1e`](https://github.com/grokify/gogit/commit/4cb1c1e))
- `gitscan pushed [count] [directory]`: list the most recent commits already pushed on the current branch, newest first; `count` defaults to 10 and is an optional positional (either order relative to the directory) ([`21882fb`](https://github.com/grokify/gogit/commit/21882fb))
- `Repo.PushedCommits(ctx, limit)` and `PushedResult`: library API returning the most recent pushed commits and the baseline they were read from ([`21882fb`](https://github.com/grokify/gogit/commit/21882fb))
- `LogOptions.Rev`: log commits reachable from an arbitrary revision (e.g. a push baseline) instead of the default HEAD ([`21882fb`](https://github.com/grokify/gogit/commit/21882fb))
- `gitscan pending` shows a live progress bar on stderr while sweeping multiple repositories, keeping stdout clean for piping and JSON ([`8432515`](https://github.com/grokify/gogit/commit/8432515))

### Changed

- `Repo.PendingCommits` now returns a `PendingResult` carrying the resolved push baseline (upstream, matching remote-tracking branch, or empty when never pushed) so callers can label the report; the CLI adds an `unpushed-all` mode for branches with no push target ([`85243b6`](https://github.com/grokify/gogit/commit/85243b6))
- The commit renderer was generalized from pending-only (`PendingReport`/`Pending`) into a shared, list-based `CommitReport`/`Commits` API used by both `pending` and `pushed`, with an invariant multi-repo output shape ([`ca377e8`](https://github.com/grokify/gogit/commit/ca377e8))
- The shared `recurse` flag was scoped per subcommand and root-only flags moved out of the shared file, leaving no shared mutable flag state ([`542b9c6`](https://github.com/grokify/gogit/commit/542b9c6))

### Fixed

- `gitscan pending` previously errored `no upstream configured` whenever `@{upstream}` did not resolve, which also blocked repos that simply had not been pushed yet; it now reports those commits as pending. An unborn or detached HEAD yields no pending commits rather than an error ([`85243b6`](https://github.com/grokify/gogit/commit/85243b6))
- Build-from-source instructions in the README pointed at the wrong directory and build path (`cd gitscan` / `go build .`); corrected to `cd gogit` / `go build ./cmd/gitscan` ([`54a31fa`](https://github.com/grokify/gogit/commit/54a31fa))

### Documentation

- README and docs/index.md: documented fleet `pending`, the `pushed` subcommand, the positional scan directory, and the previously-undocumented `since --unpushed` flag ([`54a31fa`](https://github.com/grokify/gogit/commit/54a31fa))
- README: recorded fleet-sweep cold/warm cache performance (~22s cold vs ~5.5s warm across ~640 repos) and a planned `--modified-since` prefilter to skip unchanged repositories ([`34d6428`](https://github.com/grokify/gogit/commit/34d6428))

### Tests

- Coverage for `PushedCommits` (upstream, limit and newest-first ordering, no-upstream), fleet `pending` (multi-repo grouping, summary, and the single-repo `--since-commit` guard), and the list-based renderer (fleet hiding of clean repos, JSON envelope shape, and per-repo error reporting) ([`4cb1c1e`](https://github.com/grokify/gogit/commit/4cb1c1e))

## [v0.9.0] - 2026-09-07

### Highlights

- New `gitscan pending` subcommand and `Repo.PendingCommits`/`Repo.HasUpstream` library API report commits that exist locally but haven't been pushed, or that come after an explicit commit hash — as an aligned terminal table, copy-pasteable markdown, or JSON for agents
- `gitscan pending` timestamps are now RFC 3339 with an explicit UTC offset and a weekday column, with a new `--tz` flag to normalize every timestamp to `local` or `utc` instead of each commit's own recorded offset
- Consolidated two independent, disagreeing AI co-author detectors onto one canonical registry, fixing a bug where a bare "Claude Code" co-author was misread as model "Code"
- Fixed `gitscan since 1m` (and other bare-month durations) silently resolving as minutes instead of 30-day months
- `gitscan` no longer silently reports a repo as clean when `git status` itself fails to run
- Moved CLI logic out of `cmd/*.go` into the `scanner` library and two new internal packages (`internal/render`, `internal/cliutil`), raising `scanner` coverage from 41.2% to 90.7% and `cmd` from 0% to 82.8%

### Added

- `Repo.PendingCommits(ctx, sinceCommit)`: commits ahead of the current branch's upstream, or after an explicit commit hash; oldest-first ([`a50d81b`](https://github.com/grokify/gogit/commit/a50d81b))
- `Repo.HasUpstream(ctx)`: whether the current branch has an upstream (remote-tracking) branch configured ([`a50d81b`](https://github.com/grokify/gogit/commit/a50d81b))
- `gitscan pending [directory]`: report unpushed commits for a single repo, with `--since-commit <hash>` to filter from an explicit commit instead ([`a50d81b`](https://github.com/grokify/gogit/commit/a50d81b))
- `gitscan pending --format`: `table` (aligned via `text/tabwriter`, default), `markdown` (copy-pasteable), or `json` (structured, for agents) ([`45e65d1`](https://github.com/grokify/gogit/commit/45e65d1))
- `gitscan pending --tz`: `original` (default, each commit's own recorded offset), `local` (this machine's timezone), or `utc`; table/markdown gained a weekday column and JSON a `weekday` field ([`d5f5fa1`](https://github.com/grokify/gogit/commit/d5f5fa1))
- `scanner.ParseDuration`: duration-string parsing (`7d`, `2w`, `1m`, `24h`) as public, directly-testable library API ([`d598cee`](https://github.com/grokify/gogit/commit/d598cee))
- `RepoResult.MatchesDependency` and `RepoResult.HasIssues`: dependency-filter and issue-detection predicates promoted from `cmd/dep.go`/`cmd/root.go` to reusable `scanner` methods ([`d598cee`](https://github.com/grokify/gogit/commit/d598cee))

### Changed

- `since`/`dep`: removed an unreachable directory fallback branch left over from an earlier flag structure ([`44628cc`](https://github.com/grokify/gogit/commit/44628cc))

### Fixed

- AI co-author detection: `aicoauthor.go` and `authorship.go` maintained separate registries that disagreed on the same commit; `AnalyzeAuthorship` now builds on the single registry in `aicoauthor.go`, and its Claude model pattern requires a version number so the bare tool name is never misread as a model ([`fcb53b8`](https://github.com/grokify/gogit/commit/fcb53b8))
